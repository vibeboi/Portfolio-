# Daodu Titoluwani — Portfolio

A React + Vite portfolio website.

## Requirements
- Node.js 22.12+ (or Node.js 20.19+)
- npm

## Run locally
1. Extract the ZIP.
2. Open a terminal in the `Main` folder (the folder containing `package.json`).
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production check
- `npm run build` creates the production site in `dist/`.
- `npm run preview` serves the production build locally.

## Personalise before publishing
- Edit the profile, project details, skills and education in `src/component/main/page.js`.
- Add your real GitHub and LinkedIn profile URLs in `profile.links`.
- The contact form uses `mailto:` and opens the visitor's email app; it does not send messages through a server.
